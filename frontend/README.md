## Frontend da loja KAUCELL

Este diretório concentra todo o **código de frontend** da aplicação:

- **Páginas:** `index.html`, `produtos.html`, `servicos.html`, `blog.html`, `admin.html`
- **Estilos:** `styles.css`
- **Scripts:** `script.js`, `admin.js`, `servicos.js`, `servicos-dados.js`

O build do projeto (`npm run build`) copia o conteúdo de `frontend/` para `public/`, que é usado no deploy (Vercel) ou ao servir o site localmente.
