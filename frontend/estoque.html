Conecte seu WhatsApp para receber alertas automáticos quando uma peça estiver em falta ou com estoque baixo.

Como conectar:

  1. Acesse callmebot.com e siga os passos para autorizar o bot no seu WhatsApp.
  2. Copie a API Key que o CallMeBot enviar.
  3. Informe seu número (com DDD) abaixo, cole a API Key e clique em Salvar conexão.
  4. Use Enviar teste para confirmar que está funcionando.
